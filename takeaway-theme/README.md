# Takeaway Theme v0.2.6

Production-polish theme pass for Takeaway OS:

- Version-aware bundled Takeaway OS install/update flow.
- Clearer bundled plugin status badges and Launchpad actions.
- Updated bundled manifest for Takeaway OS `1.2.5`.
- Header logo now reads the correct Takeaway branding setting.
- Theme skins now map to the Takeaway OS branding skin setting.
- Added burger, pizza, clean delivery and charcoal CSS skin variables.
- Header scroll polish and mobile ordering spacing improved.
- Navigation has a small fallback label if no menu has been assigned.

The theme remains visual-only. Ordering, menu, CRM, reports, modules and setup logic belong to Takeaway OS and WooCommerce.


## v0.2.6
- Bundles Takeaway OS `1.2.5` for the controlled first-client beta hardening pass.
- Keeps the bundled updater version-aware: older installs can update, newer installs are not downgraded.
