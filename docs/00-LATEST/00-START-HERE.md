# Start Here

This folder contains the current docs you are most likely to want first.

Read them in this order:

1. `01-CURRENT-STATUS-HANDOVER.md`
   This is the main current-state snapshot for the build, staging, release status, blockers, and handover notes.
2. `02-INSTALL.md`
   Use this for install or deployment steps.
3. `03-TESTING.md`
   Use this for test flows and verification steps.
4. `04-TROUBLESHOOTING.md`
   Use this when something is broken or behaving unexpectedly.
5. `05-UPDATE-ARCHITECTURE.md`
   Use this before commercial rollout, GitHub releases, or client-specific custom work.

Release reports also live in the project root:

- `takeaway-v1.3.11-production-readiness.txt`
- `takeaway-v1.3.11-critical-check.txt`

Everything older, deeper, or more reference-heavy has been moved into `docs/archive/`.
